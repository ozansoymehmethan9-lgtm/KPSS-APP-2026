# 🎯 KPSS Takip Sistemi

Modern, hızlı ve kullanımı kolay bir KPSS (Kamu Personeli Seçme Sınavı) hazırlık takip uygulaması.

## ✨ Özellikler

- 📊 **Gelişmiş İstatistikler**: Günlük soru çözümü ısı haritası, net gelişim grafikleri ve ders başarı oranları.
- ⏳ **Geri Sayım Sayacı**: Sınavlara ve başvurulara ne kadar süre kaldığını anlık takip edin.
- 📓 **Dijital Yanlış Defteri**: Yanlış yaptığınız soruların ekran görüntülerini kaydedin ve üzerine notlar alın.
- 📝 **Test & Deneme Takibi**: Çözdüğünüz testleri kaydedin, detaylı deneme analizleri yapın.
- 🎯 **Hedef Sistemi**: Günlük soru hedefleri belirleyin ve ilerlemenizi görün.
- 🏠 **Hoca Tavsiyeleri**: Alanında uzman KPSS hocalarının güncel listesi.
- 💪 **Motivasyon Bölümü**: Motivasyon sözleri, müzik ve podcast önerileri.
- 🧠 **Net Hesaplama**: KPSS puan ve net hesaplama aracı.

## 🚀 Kurulum

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/kullaniciadi/KPSS-Takip-Sistemi.git
   cd KPSS-Takip-Sistemi
   ```

2. Gerekli kütüphaneleri yükleyin:
   ```bash
   pip install -r requirements.txt
   ```

3. Uygulamayı başlatın:
   ```bash
   python src/main.py
   ```

## 🛠 Kullanılan Teknolojiler

- **Dil**: Python 3.x
- **UI Framework**: CustomTkinter
- **Veritabanı**: SQLite3
- **Grafikler**: Matplotlib
- **Görüntü İşleme**: Pillow (PIL)
